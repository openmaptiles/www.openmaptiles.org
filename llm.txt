Machine-readable site index, replacing the one scripts/generate-seo-assets.js
wrote into public/. That script carried its own hardcoded copy of every title and
description; here the same document is generated from the pages and _data the site
already has, so it cannot drift.

Two deliberate differences from the generated file:

- URLs carry trailing slashes. The old file emitted `/about`, `/docs/schema` and
  so on, which cost every consumer a redirect hop under `permalink: pretty`.
- Style names come from _data/styles.json. The generator title-cased the slug, so
  it wrote "Style: Maptiler Basic" and "Style: Osm Bright" while writing
  "Style: OSM OpenMapTiles" correctly in the same list. See open item 14.

Titles are the server-rendered ones throughout, matching the choice recorded in
open item 8.
{%- endcomment -%}
