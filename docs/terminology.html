The entries themselves are deliberately absent from the nav — they are reference material reached from this list or from search, and adding 30+ terms to a sidebar that currently holds 21 links would bury the task-based guides. The sidebar's prefix-match active rule keeps "Terminology" highlighted while an entry is open, so the section still reads as the current location. Entries are the docs-collection documents under _docs/terminology/, identified by `category: terminology` rather than by path — `where` on a front-matter field is what the rest of the site does, and a document that forgets the category would also be missing from any future category-driven UI, so one rule fails loudly rather than two failing separately.
