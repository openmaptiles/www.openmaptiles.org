What is the Open Tile Schema?

The Vector Tile Schema is an open, production-ready specification for structuring map data. Built on OpenStreetMap, Natural Earth, and other open data sources, it defines how geographic features are organized in vector tiles.

It captures common cartographic decisions - layers, attributes, and naming - in a clear data model that helps you build maps faster and more consistently.

Free to use, modify, and extend. The schema can be adapted or reimplemented in any project with attribution.
