The title and description fallback chains are order-sensitive; each step is spelled out below rather than collapsed, so a change to one cannot silently shift another. {%- endcomment -%} {%- assign site_name = "OpenMapTiles" -%} {%- assign default_title = "OpenMapTiles – World maps you can self-host" -%} {%- assign default_desc = "Vector tiles from OpenStreetMap and OpenData to create world maps for web and mobile." -%} {%- comment -%} Collection docs get the " – OpenMapTiles Documentation" suffix, matching the docs collection.
