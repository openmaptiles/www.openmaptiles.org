About OpenMapTiles

OpenMapTiles is the fastest way to run open-source maps. In minutes, you can start serving optimized vector map tiles ready for use in websites, apps, or products.

{% include icons/rocket-launch.svg %}

Project origins

OpenMapTiles is the successor to OSM2VectorTiles, which won the OpenStreetMap Innovation Award in 2016. It started as a bachelor's thesis at OST University in cooperation with Klokan Technologies. Today, it is maintained by the MapTiler team.

The project is primarily maintained by developers and cartographers from the MapTiler team as part of their open-source initiative.

{% include icons/map-trifold.svg %}

Open styles & schema

OpenMapTiles is a full map stack. We provide beautiful open map styles that you can adapt for your project or commercial product.

Our Vector Tile Schema encodes cartography decisions from OpenStreetMap and Natural Earth. It is 100% free to use, extend, and build upon.

{% include icons/database.svg %}

Ready-to-use map data

We turn public OpenStreetMap data into ready-to-use vector tile packages for the whole planet, individual countries, and major cities.

Web
Interactive maps using modern JavaScript viewers.
Mobile
Native iOS and Android apps, including offline use.
Print
High-resolution raster images for physical maps.

For the fastest start, you can download preprocessed global datasets from commercial providers such as MapTiler Data, or skip downloading altogether and get maps instantly with MapTiler Cloud.

{% include icons/lock-key-open.svg %}

No vendor lock-in

The entire project is open-source (BSD{{ " + " }}CC-BY) and relies on open standards. You can run the entire pipeline yourself.

  • Adopt our workflow and generate tiles in-house.
  • Host your map data completely independently.
  • Or use commercial APIs and data from MapTiler to speed up deployment.
