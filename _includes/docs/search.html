{%- comment -%} Docs search box. Replaces Pagefind's default UI with lunr, per plan §8. The DOM shape is Pagefind's, element for element, because the stylesheet targets that markup and the sidebar gate compares by structural path: div (was `w-full`) └ div (was `.pagefind-ui-container`, carries the custom properties) └ div (was `.pagefind-ui`) └ form (was `.pagefind-ui__form`, with the magnifier as ::before) ├ input ├ button (clear, suppressed until there is a query) └ div (drawer, hidden until a search has run) Everything inside the drawer is built by search.js from search.json — Pagefind built its results at runtime too, so there is nothing to server-render. The strings are Pagefind's English defaults, read out of its own translation table, so the placeholder and clear label say exactly what they say today. {%- endcomment -%}
